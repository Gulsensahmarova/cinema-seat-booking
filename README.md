# 🎬 Baku Film Center - Seat Booking System

This is a responsive seat booking application developed as part of the **Meta Front-End Developer Professional Certificate**.

## ✨ Features
* **Dynamic Seat Generation:** Automatically generates 156 seats.
* **Sector Selection:** Different prices for Sector A, B, and VIP.
* **Real-time Calculation:** Calculates total price as you select/deselect seats.
* **3D Visuals:** A stylized 3D screen with realistic lighting effects.

## 🛠️ Technologies Used
* HTML5
* CSS3 (Flexbox, Grid, 3D Transforms)
* JavaScript (DOM Manipulation, Event Listeners)
